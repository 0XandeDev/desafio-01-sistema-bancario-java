# Desafio 01 - Sistema Bancário em Java

## Sobre o projeto
Projeto desenvolvido em Java para simular operações básicas de uma conta bancária por meio de um menu interativo no console.

## Funcionalidades
- Exibição dos dados do cliente.
- Consulta de saldo.
- Transferência de valores.
- Recebimento de valores.
- Atualização do saldo após as operações.
- Validação de saldo disponível para transferências.
- Opção para encerrar o programa.

## Conceitos praticados
- Entrada de dados com Scanner.
- Variáveis e tipos de dados.
- Estruturas condicionais (if e else if).
- Estrutura de repetição while.
- Operadores aritméticos.
- Validação de dados e lógica de programação.
- Menus interativos no console.

## Tecnologias utilizadas
- Java
- IntelliJ IDEA

## Objetivo
Praticar os fundamentos da linguagem Java por meio da
simulação de operações bancárias e do desenvolvimento
da lógica de programação.
